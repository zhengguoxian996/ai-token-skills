# AI-TOKEN Agent Skills

面向 AI-TOKEN 用户的跨工具 Agent Skills 仓库。

## 可用技能

- [图片生成（Ai-token）](图片生成-ai-token/SKILL.md)：使用个人 API Key 选择线路、模型、积分与参数，生成图片或上传参考图编辑图片，并查询、恢复原任务和保存本地结果。

## 技能身份与更新

每个发布技能在 `SKILL.md` 中携带固定的 `metadata.skill_id`（UUID）。图片生成技能的 ID 为 `71771dc1-c99e-4a23-974a-3d9d79b54d3e`。升级、改名和移动目录时永久保留 ID；独立的新技能必须生成新 ID。版本号、名称、路径、Git 提交和内容摘要分别维护。

每个新技能还必须声明字符串 `metadata.version`，首次正式版本为 `"1.0.0"`。修复使用 `1.0.1`，兼容功能增加使用 `1.1.0`，不兼容变更使用 `2.0.0`；每次发布内容变化均提高版本号，固定技能 ID 保持不变。版本采用不带前导零的三段整数；升级判断按数值段比较，并结合发布记录、文件摘要和本地修改情况决定覆盖。

发布前安装 `requirements-dev.txt` 中的校验依赖，运行 `python scripts/validate_skills.py`，同时检查结构、必填版本和 ID 唯一性。现有无 ID 技能应先在原路径补 ID 并同步，再移动目录；已经改名的官方图片技能有明确的旧目录绑定。相同 ID 来自其他仓库时，应先确认来源迁移，不能直接覆盖或按相似名称合并。

## 安装

将需要的完整技能目录复制或链接到所用 Agent 工具支持的 Skills 目录。保留技能目录中的 `SKILL.md` 以及随附的 `agents`、`references`、`scripts` 或 `assets`；具体发现与安装方式以所用工具的文档为准。

`agents/openai.yaml` 是 OpenAI/Codex 的可选界面适配，不是核心技能流程的运行前提。

技能使用中文名称与中文技能根目录。当前显示名称为“图片生成（Ai-token）”，目录及 `SKILL.md` 标识为 `图片生成-ai-token`，调用名为 `$图片生成-ai-token`；保留标准文件名和技术脚本名。

从旧 `ai-token-image-generation` 目录升级时，请保留当前用户原有的完整 `.local/` 并迁移到新安装目录，避免丢失密钥、幂等键和任务记录。不要同时运行两个安装副本，不要把私有数据放进分发包。依赖脚本固定摘要的宿主桥接器需先适配验证新版脚本，再更新安装。

## 安全说明

- 使用前阅读目标技能的输入要求、执行与结果恢复流程。
- 云端地址、工作流、用户文件和凭据不得提交到本仓库。
- 付费或消耗算力的执行必须获得明确授权，并设置最大提交次数。
